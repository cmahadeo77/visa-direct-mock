# progress/

Lightweight project-management notes for this repo, kept next to the code.

| File | Purpose |
|---|---|
| [STATUS.md](STATUS.md) | Current snapshot: what works, what's partial, known gaps |
| [ROADMAP.md](ROADMAP.md) | Prioritized milestones as checklists |
| [LOG.md](LOG.md) | Dated work log (newest first) |

**Conventions**
- Update `STATUS.md` whenever a component changes state (Planned -> In progress -> Working).
- Check off `ROADMAP.md` items in the same commit that completes them.
- Add a `LOG.md` entry for each working session: date, what changed, what's next.
